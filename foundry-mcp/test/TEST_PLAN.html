1. Scope & Objectives

In Scope

  • 12 Foundry tools — project bootstrap, resource management, contribution workflow
  • 8 ServiceNow core tools — instance connectivity, querying, scripting
  • 6 AI Agent tools — list, get, trace, errors, execute, create
  • 4 Now Assist Skill tools — list, get, execute, create
  • Shared infrastructure — connection guards, table discovery, client CRUD, error types
  • MCP protocol — stdio transport, NDJSON, initialize handshake, tool listing, tool dispatch
  • Security — script injection, query injection, credential handling

Out of Scope

  • Claude Code IDE integration (handled by MCP SDK)
  • Golden repo CI/CD (separate repo with its own tests)
  • ServiceNow platform bugs (we test our tools, not the platform)

Test Phases

OfflineNo network needed. Tests tool definitions, schemas, guards, file operations. Fully automated.
MockUses mock HTTP responses or simulated golden repo. No live instance needed.
LiveRequires a real ServiceNow dev/test instance. Manual or semi-automated.
SecurityValidates input sanitization, injection prevention, credential safety.
E2EMulti-tool workflows exercising real-world usage patterns.

Priority Legend

P0 — BlockerMust pass before any release. Broken = server won't work.
P1 — CriticalCore functionality. Must pass for the tool to be usable.
P2 — ImportantEdge cases and validation. Should pass but won't block release.
P3 — Nice to havePerformance, cosmetic, informational.

17. Security Tests

Critical: These tests validate that the MCP server cannot be used to execute malicious operations on a ServiceNow instance or the local filesystem.
IDTest CaseStepsExpected ResultPass
Script Safety
SEC-001 Shell metacharacters blocked in exec Pass ; rm -rf / in a resource name Rejected by validateResourceName()
SEC-002 Safe exec uses spawn (no shell) Verify safeExec uses spawn with shell: false No shell interpretation of metacharacters
SEC-003 Path traversal blocked Pass ../../etc/passwd as resource name Rejected: names must be lowercase alphanumeric with hyphens
ServiceNow Query Safety
SEC-004 Query injection attempt Pass malicious encoded query: active=true^ORDERBYDESCsys_created_on;DROP TABLE incident Query passed as-is to ServiceNow API (which sanitizes server-side). No local shell execution.
SEC-005 Script mode enforcement Call servicenow_script with mode: "readonly" and destructive script Script runs in read-only context on the ServiceNow side
Credential Safety
SEC-006 Credentials not in tool output Connect with password, then call status Password/token never appears in any tool response text
SEC-007 Credentials file permissions Check ~/.servicenow/credentials.json file read File read with appropriate permissions, no logging of contents
Create Tool Safety
SEC-008 aia_create defaults to dry-run Call aia_create without setting dryRun No records created on instance (dry-run: true by default)
SEC-009 skill_create defaults to dry-run Call skill_create without setting dryRun No records created on instance (dry-run: true by default)
SEC-010 Tool script safety in aia_create Create agent with tool containing gs.log() in script Tool created but execution will hang (per tool script rules). Consider adding a warning.

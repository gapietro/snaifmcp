Phase 6: Safety & Security Validation (5 tests)

Instructions: These tests verify that all content follows ServiceNow security best practices. Search the content files for security anti-patterns.
Test 6.1
GlideRecordSecure Usage

Action: Search tool scripts in tool-script-cookbook.md for security compliance.

# Should find GlideRecordSecure, not plain GlideRecord
grep -n "GlideRecord" foundry-golden/context/tool-script-cookbook.md

# Should NOT find these dangerous patterns
grep -n "gs\.\|GlideDateTime\b" foundry-golden/context/tool-script-cookbook.md
Verify:
  • All tool scripts use GlideRecordSecure (not plain GlideRecord)
  • No gs.* calls in tool scripts (except gs.info() for logging if needed)
  • No GlideDateTime in tool scripts (use safe alternatives)
Test 6.2
ACL Enforcement (addUserEncodedQuery)

Action: Verify all recipe scripts in the cookbook include ACL enforcement.

# Every recipe with GlideRecordSecure should also have addUserEncodedQuery
grep -c "addUserEncodedQuery" foundry-golden/context/tool-script-cookbook.md
Verify:
  • Every recipe that queries records includes addUserEncodedQuery()
  • The call appears after addQuery() and before query()
Test 6.3
Write Operations Supervised

Action: Search the cookbook for recipes that write data (insert, update, delete).

# Find write operations
grep -n "\.insert\|\.update\|\.deleteRecord\|\.setValue" foundry-golden/context/tool-script-cookbook.md
Verify:
  • All recipes with write operations are marked as Supervised mode
  • Supervised mode is clearly documented in the recipe metadata
Test 6.4
Agent Guardrails Present

Action: Check that agent instruction templates include guardrails/rules sections.

grep -i "guardrail\|rules\|constraint\|boundary\|never\|must not" foundry-golden/context/agent-instruction-templates.md
Verify:
  • Instruction templates include a Rules or Guardrails section
  • Rules cover: data safety, scope limits, escalation triggers
  • Templates warn against common prompt injection patterns
Test 6.5
QA Debugger Checks Guardian

Action: Verify the QA Debugger's diagnostic workflow includes checking for Now Assist Guardian blocks.

grep -i "guardian\|blocked\|safety" foundry-golden/subagents/qa-debugger/AGENT.md
Verify:
  • QA Debugger workflow includes a step to check for Guardian blocks
  • Knows how to diagnose Guardian-related failures
  • References now-assist-guardian-governance.md or equivalent context

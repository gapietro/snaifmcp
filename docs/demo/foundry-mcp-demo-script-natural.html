1.3 Set Up ServiceNow Credentials
"Credentials are stored in the macOS Keychain — no plaintext passwords on disk. Supports multiple named profiles for dev, staging, and customer instances."

Step A — Store password in macOS Keychain:

Terminal
security add-internet-password -s your-instance.service-now.com -a admin -w

Step B — Create the credentials profile:

Terminal
mkdir -p ~/.servicenow
cat > ~/.servicenow/credentials.json << 'EOF'
{
  "profiles": {
    "dev": {
      "instance": "your-instance.service-now.com",
      "username": "admin",
      "authType": "keychain"
    }
  }
}
EOF

With authType: "keychain", the password is retrieved from macOS Keychain at connect time — never stored in the JSON file.

1.4 Restart Claude Code
"MCP servers are started at session launch — always restart after registering a new one."

Exit and relaunch Claude Code. In the new session, type /mcp to verify.

Expected

Symptom Likely Cause Fix
Claude doesn't call any Foundry tools MCP server not connected Run /mcp — if foundry missing, re-run claude mcp add
Old template names in responses (sparc-starter) Stale MCP server process Restart Claude Code — MCP servers load at session start
Foundry list/search returns empty Golden repo not cached yet First run auto-clones; needs gh auth login
ServiceNow connection fails Wrong credentials or instance URL Check ~/.servicenow/credentials.json and verify Keychain entry: security find-internet-password -s instance -a user
Claude asks "which tool should I use?" Ambiguous prompt Be more specific: add "using Foundry" or "on ServiceNow"
Script runner returns empty Wrong application scope (keynexus) Set active application to Global in ServiceNow UI

foundry_promote fails GitHub CLI not authenticated gh auth login

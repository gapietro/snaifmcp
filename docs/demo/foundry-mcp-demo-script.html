Installation & Configuration
~5 min
0 / 4
▶
1.1 Clone and Build
💬 "The MCP server lives in the Now-AI-Foundry GitHub org. One command to get it — GitHub CLI handles auth automatically."
bash 
gh repo clone Now-AI-Foundry/tool-foundry-mcp ~/projects/tool-foundry-mcp
cd ~/projects/tool-foundry-mcp
npm install
npm run build
verify 
ls dist/index.js   # should print: dist/index.js
1.2 Register with Claude Code
💬 "Register once at user scope and it's available in every project — no per-project config needed."
bash 
# User scope — available in all Claude Code sessions
claude mcp add --scope user --transport stdio foundry -- \
  node ~/projects/tool-foundry-mcp/dist/index.js

claude mcp list
expected foundry stdio node ~/projects/tool-foundry-mcp/dist/index.js ● connected
📌
For team-shared projects add a .mcp.json to the project root with "args": ["/absolute/path/to/dist/index.js"] instead.
1.3 Set Up ServiceNow Credentials
💬 "Credentials are stored in the macOS Keychain — no plaintext passwords on disk. Supports multiple named profiles for dev, staging, and customer instances."

Step A — Store password in macOS Keychain:

bash 
security add-internet-password -s your-instance.service-now.com -a admin -w

Step B — Create the credentials profile:

bash 
mkdir -p ~/.servicenow
cat > ~/.servicenow/credentials.json << 'EOF'
{
  "profiles": {
    "dev": {
      "instance": "your-instance.service-now.com",
      "username": "admin",
      "authType": "keychain"
    }
  }
}
EOF
📌
With authType: "keychain", the password is retrieved from macOS Keychain at connect time — never stored in the JSON file.
1.4 Restart Claude Code & Verify
💬 "MCP servers start at session launch — always restart after registering a new one."

Exit and relaunch Claude Code. In the new session:

claude code 
/mcp
expected foundry ● connected 38 tools available

Bootstrap a POC Project
~5 min
0 / 7
▶
💬 "This is the main workflow — zero to fully configured POC in under a minute."
3.1 Create and Initialize
bash 
mkdir ~/projects/my-poc
cd ~/projects/my-poc

Start Claude Code from that directory and prompt:

claude code prompt 
Initialize this Foundry POC project using the foundry-poc template.
📌
foundry_init bootstraps the current directory — you must be inside the project folder before running it.
expected Project "my-poc" initialized at ~/projects/my-poc Template: foundry-poc - Context: Now Assist platform, GenAI framework, Agentic patterns - Skills: Now Assist skill builder, API integration ... Next steps: 1. Review CLAUDE.md and update project details 2. Start building with Claude Code!
3.2 Inspect What Was Created
💬 "Claude Code automatically reads everything in .claude/ — context files give it domain knowledge, skills teach it workflows."
bash 
find ~/projects/my-poc -not -path '*/\.*' | sort
ls ~/projects/my-poc/.claude/context/
ls ~/projects/my-poc/.claude/skills/
expected structure my-poc/ ├── CLAUDE.md ├── .gitignore ├── 00_Inbox/ (calls/, emails/, notes/) ├── 01_Customers/ ├── 10_PromptTemplates/ ├── 20_Demo_Library/ ├── 99_Assets/ └── .claude/ ├── context/ ← now-assist-platform.md, genai-framework.md, agentic-patterns.md └── skills/ ← now-assist-skill-builder/, api-integration/
3.3 Add an Additional Resource
💬 "After init you can keep adding resources as your POC evolves — no need to re-initialize."
mcp tool 
foundry_add type="context" name="security-patterns" projectPath="~/projects/my-poc"
verify 
ls ~/projects/my-poc/.claude/context/   # security-patterns.md should appear
3.4 Check for Updates
mcp tool 
foundry_sync projectPath="~/projects/my-poc" dryRun=true

Connect to ServiceNow
~8 min
0 / 10
▶
💬 "Now let's connect to a live instance and explore the read-only introspection tools — this is what makes Claude a hands-on ServiceNow collaborator rather than just a code generator."
4.1 Connect
mcp tool 
servicenow_connect profile="dev"
expected Connected to your-instance.service-now.com User: admin
4.2 Verify Status & Instance
mcp tool 
servicenow_status
servicenow_instance
4.3 Query a Table
💬 "Any table, any filter, any fields — great for exploring data structure before building agents."
mcp tool 
servicenow_query table="sys_user" query="active=true" fields=["user_name","name","email"] limit=5
mcp tool 
servicenow_query table="sys_properties" query="nameLIKEglide.ui" fields=["name","value"] limit=5
4.4 Run a Background Script
💬 "Background scripts for anything the REST API can't do — complex lookups, cross-table aggregations, on-the-fly calculations."
mcp tool 
servicenow_script script="var count = new GlideAggregate('incident'); count.addAggregate('COUNT'); count.query(); count.next(); var total = count.getAggregate('COUNT'); var gr = new GlideAggregate('incident'); gr.addAggregate('COUNT'); gr.addQuery('state', 1); gr.query(); gr.next(); var newCount = gr.getAggregate('COUNT'); gs.info('Total incidents: ' + total); gs.info('New incidents: ' + newCount);"
💡
For instance version info, use servicenow_instance instead — it returns the full build tag directly.
4.5 Browse AI Agents
💬 "The AIA tools let Claude introspect the entire agentic layer — agents, use cases, flows, skills. Full read-only visibility."
mcp tool 
servicenow_aia_list limit=10
servicenow_aia_list status="active" limit=10
ℹ️
The active filter may use client-side fallback on some instances due to a REST ACL — this is expected and handled automatically.
4.6 Inspect an Agent

Pick a sys_id from the previous list:

mcp tool 
servicenow_aia_get agent="<sys_id>" includeTools=true includeStats=true
4.7 Browse Use Cases & Flows
mcp tool 
servicenow_aia_usecase_list limit=5
servicenow_flow_list name="LLM" limit=5
4.8 Inspect a Skill
mcp tool 
servicenow_skill_list limit=10

Pick a skill name from the output:

mcp tool 
servicenow_skill_get skill="<skill-name>"

▶
💬 "All creation tools support dryRun=true — shows exactly what would be built without touching the instance. Great for planning, reviewing with a customer, or catching problems before deployment."
5.1 Preview an AI Agent
mcp tool 
servicenow_aia_create
  agentName="Demo Support Agent"
  agentDescription="Handles common IT support requests"
  agentInstructions="You are an IT support agent. Help users resolve common issues."
  agentRole="Support"
  agentProficiency="Intermediate"
  dryRun=true
5.2 Forbidden API Detection
💬 "Foundry scans tool scripts for ServiceNow APIs that aren't allowed in Skills Kit tools — catches issues before you deploy and get a cryptic runtime error."
mcp tool 
servicenow_aia_create
  agentName="Test Agent"
  agentDescription="Test"
  agentInstructions="Test agent"
  dryRun=true
  tools=[{"name":"Risky Tool","description":"Uses gs.info","inputSchema":[],
          "script":"(function(inputs) { gs.info('test'); return {}; })(inputs);"}]
expected ⚠️ WARNING: Forbidden API detected in tool script gs.info() is not available in Skills Kit execution context
5.3 Preview a Skill (8-Phase Plan)
💬 "Skill creation is the most complex flow — 8 phases, ~24 API calls. The dry-run shows the full plan so you know exactly what's going to happen."
mcp tool 
servicenow_skill_create
  skillName="Demo Summarizer Skill"
  description="Summarizes IT incident descriptions"
  promptTemplate="Summarize this incident in 2-3 sentences: {{incident_description}}"
  inputs=[{"name":"incident_description","label":"Incident Description",
           "description":"The incident text to summarize"}]
  dryRun=true
5.4 Disconnect
mcp tool 
servicenow_disconnect

💬 "The contribution workflow is how the golden repo grows. Build something useful in a POC, validate it, and promote it back — everyone on the team benefits immediately."

The flow:

foundry_new → scaffold  ·  foundry_validate → quality check  ·  foundry_promote → PR to golden repo

6.1 Scaffold a New Resource
mcp tool 
foundry_new type="skill" name="my-new-skill" description="Does something useful" projectPath="~/projects/my-poc"
6.2 Validate Before Promoting
mcp tool 
foundry_validate type="skill" name="my-new-skill" projectPath="~/projects/my-poc"
📌
Skip foundry_promote during testing — it creates a real GitHub PR on the golden repo.

Troubleshooting Quick Reference
▶
Symptom Likely Cause Fix
Templates show old names
(sparc-starter, standard, minimal)		 Stale MCP server process from before rebuild Restart Claude Code completely — the new binary loads on next launch
foundry not in /mcp Not registered or wrong path in mcp add Re-run claude mcp add with the correct absolute path to dist/index.js
foundry_list returns empty Golden repo not cached yet; gh not authenticated Run gh auth login then retry — first call auto-clones to ~/.foundry/golden/
servicenow_connect fails Wrong credentials or instance URL in credentials file Check ~/.servicenow/credentials.json and verify Keychain entry: security find-internet-password -s your-instance.service-now.com -a admin
aia_list ACL error Field-level REST ACL on active column Expected on some instances — tool falls back to client-side filter automatically, no action needed
servicenow_script returns empty Wrong application scope (keynexus instances) In ServiceNow UI, set active application to Global
foundry_promote fails GitHub CLI not authenticated to Now-AI-Foundry org Run gh auth login and ensure you have org access

🧠 Why MCP Exists

The LLM can't touch files directly — it only produces text. MCP gives Claude a safe, structured API to invoke real-world capabilities (filesystem, HTTP, databases) without executing arbitrary code. Think of it as the LLM's hands.

🔌 What the MCP Protocol Does

MCP is a thin JSON-RPC contract over stdio. Claude Code starts node dist/index.js as a child process at launch, then sends tools/call messages and reads back results. The server never opens a port — no network exposure.

⚙️ How Claude Picks the Right Tool

Claude Code sends the full tool catalog (name, description, input schema) in every API request. The LLM reads descriptions and infers which tool fits the user's intent — no hardcoded routing, no keywords. Good descriptions = better tool selection.
